# 课程工具使用标识

## 说明

本课程要求“在项目报告各个部分体现出使用过本门课程介绍工具完成内容的标识”。本文件汇总项目计划、需求、设计、源码、测试和配置管理中使用的工具及证据路径，便于教师检查。

## 可放入最终报告的工具标识汇总语句

本项目在项目计划阶段使用 Project 类工具组织 WBS、里程碑、甘特图、资源计划和成本计划；在需求和设计阶段使用 UML/PlantUML 绘制用例图、活动图、类图、顺序图和组件图；在开发阶段使用 Flutter、Dart、Riverpod 和 GoRouter 完成三端课程原型；在测试阶段使用 Flutter Test、WidgetTester 和 ProviderContainer 编写自动化测试；在配置管理阶段使用 Git、`pubspec.lock` 和 CI/CD 工作流管理源码、文档和依赖版本。以上工具使用痕迹已分别写入 `docs/01_项目计划.md` 到 `docs/06_配置管理.md`，并在 `docs/08_最终项目报告.md` 中汇总为最终检查入口。
