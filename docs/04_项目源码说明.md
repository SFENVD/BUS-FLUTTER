## 启动命令

```bash
flutter pub get

# 普通用户端
flutter run --dart-define=APP_MODE=passenger

# 司机端
flutter run --dart-define=APP_MODE=driver

# 后台管理端，建议 Web 演示
flutter run -d chrome --dart-define=APP_MODE=admin
```

## 数据流说明

```mermaid
sequenceDiagram
  participant UI as Flutter 页面
  participant Provider as Riverpod Provider
  participant Repo as Mock Repository
  participant Model as Core Models

  UI->>Provider: 触发用户操作
  Provider->>Repo: 读取初始 Mock 数据
  Repo-->>Provider: 返回模型列表
  Provider->>Model: 创建或更新业务模型
  Provider-->>UI: 状态变化自动通知页面刷新
```

## 已实现原型边界

当前项目是课程大作业原型，以下能力使用 Mock 方式实现：

| 能力 | 当前实现 | 后续扩展 |
| --- | --- | --- |
| 用户登录 | Mock 账号和密码 | 后端登录、Token、权限表 |
| 支付 | Mock 微信支付和支付宝 | 接入学校支付平台或支付 SDK |
| 实时位置 | 定时模拟经纬度 | 手机 GPS 和 WebSocket |
| 地图 | Flutter 绘制 Mock 地图 | 高德地图、腾讯地图或 OSM |
| AI 调度 | 规则引擎推荐 | 调用优化算法或大模型辅助解释 |
| 数据持久化 | 内存状态 | 数据库和服务端 API |
