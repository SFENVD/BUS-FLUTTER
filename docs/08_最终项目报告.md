## 项目简介

本项目实现一个面向校园通勤场景的校车管理系统。系统通过同一套 Flutter 代码根据 `APP_MODE` 环境变量切换普通用户端、司机端和后台管理端。

普通用户可以登录、预约车次、选择座位、取消预约、Mock 支付车费、查看信用等级和通知。司机可以查看派车任务、乘客名单、日/周/月任务统计，并在发车后共享 Mock 实时位置。后台管理员可以维护车辆和司机信息，基于预约需求进行人工调度或 AI 辅助调度，查看在途车辆位置、预约客户 ETA 和运营历史数据。

当前项目是课程设计原型，不虚构真实支付、真实 GPS、真实地图 SDK 或正式后端上线能力。真实支付、真实 GPS 和正式后端均作为后续扩展方向说明。

## 运行与演示说明

安装依赖：

```bash
flutter pub get
```

普通用户端：

```bash
flutter run --dart-define=APP_MODE=passenger
```

司机端：

```bash
flutter run --dart-define=APP_MODE=driver
```

后台管理端 Web：

```bash
flutter run -d chrome --dart-define=APP_MODE=admin
```

Mock 账号：

| --- | --- | --- |
| 普通用户端 | `13800000001` | `123456` |
| 司机端 | `13800000002` | `123456` |
| 后台管理端 | `13800000003` | `123456` |

账号角色必须与当前入口一致。当前默认未配置 Supabase 时使用 Mock 数据。
