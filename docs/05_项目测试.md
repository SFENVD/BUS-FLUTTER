# 项目测试

## 课程工具标识

`[课程工具标识: Flutter Test + WidgetTester + 测试用例表]` 本部分对应“项目测试”要求，包括测试计划、测试用例和测试报告。自动化测试源码位于 `test/widget_test.dart`，测试命令为 `flutter test`。

## 测试目标

验证校车管理系统三端主要功能是否满足需求，重点覆盖普通用户预约支付取消、司机派车任务和实时位置、后台车辆司机管理、调度、实时监控、客户 ETA 和历史数据分析。

## 测试范围

| 类型 | 范围 |
| --- | --- |
| 功能测试 | 登录、预约、支付、取消、信用、任务、位置、车辆、司机、调度、分析 |
| UI 测试 | Flutter Widget Test 验证关键页面文字、按钮和弹窗 |
| 业务规则测试 | 重复预约、取消扣分、车辆司机绑定、调度确认等核心规则 |
| 回归测试 | 修改后台 ETA 后重新执行全部测试 |

## 不测试范围

## 测试策略

| 策略 | 说明 |
| --- | --- |
| 自动化优先 | 对关键主流程编写 Widget Test，保证每次修改可回归验证 |
| 端到端交互 | 通过点击 Mock 登录、按钮、弹窗和筛选项模拟真实用户操作 |
| 数据断言 | 通过界面文本断言状态变化，如支付成功、信用分变化、位置上报次数 |
| 风险聚焦 | 优先测试预约、支付、调度、位置这类容易出现状态错误的流程 |
